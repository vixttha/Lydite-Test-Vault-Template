# Published v0.0.4 release history

The standalone foundation entered Lydite's main branch at [fe7b00a](https://github.com/vixttha/Lydite-Test-Vault-Template/commit/fe7b00aa17862d7a01dfd15481594be837bc6d9f). The inherited starter and frozen archives are part of the Test Vault lineage described in the [version index](../versions/README.md). Hardening commits v0.0.3.1 through v0.0.3.30 prepared [the published v0.0.4 release](https://github.com/vixttha/Lydite-Test-Vault-Template/releases/tag/v0.0.4), validated at [the release checkout](https://github.com/vixttha/Lydite-Test-Vault-Template/actions/runs/44506598515).

## v0.0.4 changelog

- Require positive native test results, retain one outcome per case, and upload synthetic receipts for both passing and nonpassing examples.
- Verify checkout identity, select the declared .NET SDK, validate metadata and normalized test paths, and accept ordinary GitHub Markdown catalog tables.
- Rehearse the full install alongside the catalog-only starter, include the MIT notice, and ignore generated Python bytecode.
- Rebuild the historical Graphify maps from their pinned public sources, link archived v0.0.1 references, and reject malformed input in the shared quote example.
- Reject checkout drift, capture real Node and unittest outcomes, bind each case to its declared test, and record each command stage and its observed runtime.
- Exclude commented Markdown cases, keep fixtures inside the tests directory, and protect project inputs from evidence output.
- Bind v2 receipts to the selected case plan, retain matching legacy v1 receipts, and reject ambiguous shared quote observations.
- Verify executable modes in pinned archive snapshots. This integrates [the stacked Graphify change](https://github.com/vixttha/Lydite-Test-Vault-Template/pull/32).
- Generate a release-candidate receipt from a complete public run, with same-attempt job and artifact identities and the earliest supporting-artifact expiry.

## Historical review evidence

The [combined hardening review](https://github.com/vixttha/Lydite-Test-Vault-Template/pull/22) records the branch and PR runs. In that workflow, PR runs wrote `lydite-release-candidate-attempt-*` and could record the merge checkout and pull request head separately. The three supporting artifacts and the candidate receipt requested 30-day retention. Each receipt recorded the earliest expiry of its supporting artifacts.

The review covered passing, failing, skipped, and zero-test install fixtures, including an independent case after a failure. The Graphify job rebuilt three archive versions and rejected executable-mode, archive-byte, and graph-byte drift.

Use the [current receipt guide](testing.md#validation-and-release-receipts) for new PR runs and named release candidates.
